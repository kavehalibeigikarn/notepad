# یادداشت‌یار (Android)

اپلیکیشن یادداشت با Kotlin + Jetpack Compose (Material 3)، رابط فارسی راست‌به‌چپ و فونت وزیرمتن.

## امکانات
- یادداشت با عنوان، متن، چک‌لیست (با نوار پیشرفت)، موضوع، برچسب، رنگ و سنجاق
- پیوست هر نوع فایل (کپی در حافظهٔ خود برنامه)؛ پیش‌نمایش تصویر، باز کردن/اشتراک‌گذاری سایر فایل‌ها
- چیدمان بر اساس زمان (تاریخ شمسی) یا موضوع؛ مرتب‌سازی چندگانه؛ نمایش شبکه‌ای/فهرستی
- جستجو در عنوان، متن، برچسب، چک‌لیست، نام پیوست‌ها و محتوای پیوست‌های متنی (با هایلایت)
- یادآوری با تقویم شمسی (نوتیفیکیشن، تعویق ۱۰ دقیقه‌ای، بازسازی بعد از ری‌استارت گوشی)
- گروه‌بندی بر اساس زمان / موضوع / عنوان (حروف الفبای فارسی و لاتین) / بدون گروه
- ضبط صدا داخل هر یادداشت (m4a) با پخش‌کنندهٔ داخلی
- دکمهٔ دوربین: عکس و فیلم مستقیم داخل یادداشت
- مهلت‌های قانونی: خواندن سند (PDF / تصویر / DOCX / TXT) با API شخصی Claude، استخراج مهلت‌ها و ثبت چند یادآوری قبل از موعد (۳۰/۱۴/۷/۳/۱/۰ روز قبل، ساعت ۹ صبح)؛ تاریخ‌ها با تقویم شمسی و محاسبهٔ مهلت داخل خود برنامه
- بایگانی و سطل زباله، ساخت کپی
- دریافت متن/فایل از «Share» سایر برنامه‌ها به‌صورت یادداشت جدید
- پشتیبان‌گیری و بازیابی (ZIP شامل یادداشت‌ها و پیوست‌ها)
- پوسته روشن/تیره خودکار

## ساخت APK با GitHub Actions
1. یک مخزن جدید در GitHub بسازید و محتوای این پوشه را در شاخهٔ `main` پوش کنید.
2. به تب **Actions** بروید؛ workflow با نام **Build APK** خودکار اجرا می‌شود (یا دستی Run کنید).
3. پس از پایان، از بخش **Artifacts** دو فایل می‌بینید: `YaddashtYar-LITE` (بدون هوش مصنوعی؛ برای انتشار فعلی) و `YaddashtYar-FULL` (با هوش مصنوعی؛ بعداً).

### امضای ثابت (ضروری برای آپدیت بدون پاک شدن داده)
بدون یک کلید ثابت، هر ساخت با کلید تصادفی امضا می‌شود و اندروید اجازهٔ نصب روی نسخهٔ قبلی را نمی‌دهد (یا باید حذف شود و داده‌ها از بین می‌رود). یک‌بار در GitHub: **Settings ▸ Secrets and variables ▸ Actions** چهار Secret با نام‌های `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_PASSWORD`, `KEY_ALIAS` بسازید (مقادیر در فایل `GITHUB_SECRETS.txt`). فایل `release.jks` را هرگز گم نکنید و داخل مخزن نگذارید.

## یادآور با زنگ هشدار
یادآور یادداشت‌ها مثل ساعت زنگ‌دار با صدای آلارم گوشی (تکرارشونده تا ۳ دقیقه)، لرزش و صفحهٔ تمام‌صفحه با «خاموش / ۱۰ دقیقه بعد» روی قفل‌صفحه پخش می‌شود. از منوی کناری «یادآور با زنگ هشدار» را می‌شود خاموش کرد تا اعلان معمولی بیاید. مهلت‌های قانونی (۹ صبح) اعلان معمولی می‌مانند.

## جست‌وجوی محتوایی
متن داخل PDF، Word (docx)، OpenDocument، Excel (xlsx) و فایل‌های متنی ایندکس می‌شود. فایل‌های قبلی در اولین اجرای نسخهٔ جدید خودکار ایندکس می‌شوند. عکس و PDF اسکن‌شده (بدون لایهٔ متن) قابل جست‌وجو نیست.

## دو نسخه
- **lite**: بدون استخراج مهلت با هوش مصنوعی. **full**: همه‌چیز. هر دو یک `applicationId` و یک امضا دارند؛ پس نصب full روی lite، داده‌ها را نگه می‌دارد.

## تنظیم سرور (فایل `util/Cfg.kt`)
- `REGISTER_URL`: آدرس `server/register.php` برای دریافت شماره‌ها؛ `UPDATE_URL`: آدرس `server/version.json`؛ `PRIVACY_URL`: صفحهٔ حریم خصوصی.
- برای آپدیت اجباری: هنگام انتشار نسخهٔ جدید، `latestVersionCode` و `releasedAt` را در `version.json` بروزرسانی کنید. بعد از `graceDays` (پیش‌فرض ۳۰) در نسخه‌های قدیمی ساخت یادداشت/پیوست/ضبط جدید بسته می‌شود (دیدن و پشتیبان‌گیری آزاد می‌ماند). `minSupportedVersionCode` نسخه‌های خیلی قدیمی را به صفحهٔ آپدیت می‌برد.

## قوانین به‌روزرسانی (حفظ داده)
`applicationId` و کلید امضا هرگز عوض نشود؛ `versionCode` هر انتشار بیشتر شود؛ هر تغییر در ساختار دیتابیس حتماً Migration داشته باشد (از `fallbackToDestructiveMigration` استفاده نشود).

نیازی به Android Studio نیست (Gradle 8.9 و JDK 17 در workflow تنظیم شده‌اند).

## اگر پوشهٔ `.github` آپلود نشد
پوشه‌های با نقطهٔ اول (hidden) را بعضی روش‌های آپلود نادیده می‌گیرند. در GitHub روی
**Add file ▸ Create new file** بزنید، در کادر نام دقیقاً این مسیر را تایپ کنید:

`.github/workflows/build.yml`

و محتوای فایل `build.yml` (کنار همین README) را در آن Paste کنید، سپس Commit بزنید.

## مهلت‌های قانونی (برای وکلا)
1. از منوی کناری «تنظیمات هوش مصنوعی» را باز کنید و کلید API را وارد کنید.
2. یا «یادداشت از سند (استخراج مهلت)» را بزنید، یا در هر یادداشت سند را پیوست کنید و روی آیکن تقویم کنار آن بزنید.
3. فهرست مهلت‌های یافت‌شده با نقل‌قول از متن سند نمایش داده می‌شود؛ بررسی و تأیید کنید.
