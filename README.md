# یادداشت‌یار (Android)

اپلیکیشن یادداشت با Kotlin + Jetpack Compose (Material 3)، رابط فارسی راست‌به‌چپ و فونت وزیرمتن.

## امکانات
- یادداشت با عنوان، متن، چک‌لیست (با نوار پیشرفت)، موضوع، برچسب، رنگ و سنجاق
- پیوست هر نوع فایل (کپی در حافظهٔ خود برنامه)؛ پیش‌نمایش تصویر، باز کردن/اشتراک‌گذاری سایر فایل‌ها
- چیدمان بر اساس زمان (تاریخ شمسی) یا موضوع؛ مرتب‌سازی چندگانه؛ نمایش شبکه‌ای/فهرستی
- جستجو در عنوان، متن، برچسب، چک‌لیست، نام پیوست‌ها و محتوای پیوست‌های متنی (با هایلایت)
- یادآوری با تقویم شمسی (نوتیفیکیشن، تعویق ۱۰ دقیقه‌ای، بازسازی بعد از ری‌استارت گوشی)
- گروه‌بندی بر اساس زمان / موضوع / عنوان (حروف الفبای فارسی و لاتین) / بدون گروه
- ضبط صدا داخل هر یادداشت (m4a) با پخش‌کنندهٔ داخلی
- دکمهٔ دوربین: عکس و فیلم مستقیم داخل یادداشت
- بایگانی و سطل زباله، ساخت کپی
- دریافت متن/فایل از «Share» سایر برنامه‌ها به‌صورت یادداشت جدید
- پشتیبان‌گیری و بازیابی (ZIP شامل یادداشت‌ها و پیوست‌ها)
- پوسته روشن/تیره خودکار

## ساخت APK با GitHub Actions
1. یک مخزن جدید در GitHub بسازید و محتوای این پوشه را در شاخهٔ `main` پوش کنید.
2. به تب **Actions** بروید؛ workflow با نام **Build APK** خودکار اجرا می‌شود (یا دستی Run کنید).
3. پس از پایان، از بخش **Artifacts** فایل `YaddashtYar-debug-apk` را دانلود و APK را نصب کنید.

نیازی به Android Studio نیست (Gradle 8.9 و JDK 17 در workflow تنظیم شده‌اند).

## اگر پوشهٔ `.github` آپلود نشد
پوشه‌های با نقطهٔ اول (hidden) را بعضی روش‌های آپلود نادیده می‌گیرند. در GitHub روی
**Add file ▸ Create new file** بزنید، در کادر نام دقیقاً این مسیر را تایپ کنید:

`.github/workflows/build.yml`

و محتوای فایل `build.yml` (کنار همین README) را در آن Paste کنید، سپس Commit بزنید.
